# MedTrace

MedTrace is a local patient health-history application for recording symptoms over
time and preparing evidence-backed reports for clinical visits. Accounts, health
records, uploaded documents, and approved reports stay on the user's computer.

This version uses local authentication and encrypted SQLite storage. It requires
no Supabase account, cloud service, or AI API key. Summaries are generated by a
deterministic analysis engine. MedTrace does not diagnose conditions, assess risk,
recommend medication doses, or predict future cycles.

## Quick start — Windows

Prerequisites: Node.js with npm and Python 3.10 or newer, available in your terminal.
Run these commands from the repository root:

```powershell
npm ci
python -m venv backend/.venv
backend\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
npm start
```

Open **http://127.0.0.1:8765**. Leave that terminal running; press **Ctrl+C** to stop
MedTrace. **One terminal is enough.** Both `npm start` and `npm run api` rebuild the
interface and serve the application from the local Python server. Do not run
`npm run dev` for normal use.

On Windows, the application automatically creates a random encryption key protected
by Windows DPAPI. No `.env` file is required. Save the account recovery code shown
when you register. An account recovery code cannot recover a lost encryption key.

## Features

- Local registration, login, password recovery, and three-step profile setup.
- Quick, standard, and detailed daily check-ins with explicit present/absent/unknown
  observations, severity, bleeding, impact, medication, and episode details.
- Custom symptom wording, medication shortcuts, and reminders while the app is open.
- Descriptive summaries, supported longitudinal patterns, and symptom timelines.
- Treatment and healthcare-event history with encrypted PDF/image attachments.
- Clinical report scope selection, evidence review, approval, immutable history,
  PDF download, printing, and expiring/revocable links on this computer.
- Purpose-specific privacy permissions, audit history, data export, symptom-domain
  erasure, and account deletion.
- Isolated fictional trial sessions for exploring the patient workflow.

## Storage and scope

Local data is stored in `backend/data/medtrace.sqlite3`, with a protected installation
key in `backend/data/installation.key`. These files are ignored by Git. Preserve
both when backing up; on Windows the key is tied to the Windows user. Exported JSON
and PDFs are independent copies and should be stored privately.

This version does not implement cloud authentication, remote sharing, cross-device
sync, generative AI, native background notifications, or automated backup import.
Supabase authentication is planned for a later version. Historical engine metrics
come from synthetic data and do not establish clinical benefit.

## Stack

React · TypeScript · Vite · Tailwind CSS · Zustand · Python · SQLite ·
AES-256-GCM via cryptography · ReportLab. Reports reuse the TypeScript engine through
locally installed Node.js and `tsx`.
