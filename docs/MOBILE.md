# Running MedTrace as an Android app

The web prototype is wrapped, not rewritten, using [Capacitor](https://capacitorjs.com):
the same React app, same engine, same 111 tests, running inside a native Android
shell instead of a browser tab. This exists purely for a better demo surface for
the panel — nothing about the analytical engine changes.

**Why this was safe to do quickly:** `src/main.tsx` already used `HashRouter` (so the
app works from a `file://`-style load, not just a dev server) and all state lives in
`localStorage`, which Capacitor's WebView supports natively. No app code changed.

## One-time setup

1. Install **Android Studio** (comes with the Android SDK and an emulator manager):
   https://developer.android.com/studio
2. On first launch, let it install the default SDK platform + build tools when
   prompted — this needs a real internet connection, which the sandboxed environment
   this project was developed in did not have (it could generate the Android project
   but could not download `dl.google.com` artifacts to gradle-build it — that part is
   untested end-to-end and will complete the first time you open the project).

## Running it

```bash
npm install
npm run android:open   # builds the web app, syncs it into android/, opens Android Studio
```

That runs `cap sync`, which copies the latest `dist/` build into
`android/app/src/main/assets/public` and opens the `android/` folder as an Android
Studio project. In Android Studio:

1. Wait for Gradle sync to finish (first time only — downloads dependencies).
2. **Tools → Device Manager** → create a virtual device (any recent phone profile,
   e.g. Pixel 8, API 34+) if you don't have one.
3. Press **Run** (▶) with that emulator selected.

The app launches with the same persona switcher, Today/Patterns/Timeline/Brief/
Validation/Method screens, running fully offline — everything is bundled into the
APK, there is no server to reach.

## After changing the web app

Any time you change something under `src/`, re-sync before re-running in Android
Studio:

```bash
npm run android:sync
```

Then hit Run again in Android Studio (or `npx cap run android` from the CLI if you
prefer not to open the IDE).

## What this is, and isn't

- It **is** the real app — the exact same statistical engine, the exact same 111
  tests, the exact same evaluation harness output. Nothing was reimplemented for
  mobile.
- It **is not** a platform-native rewrite — there's no Kotlin/Java application logic,
  no native navigation, no platform-specific UI. If a future iteration needs actual
  native capabilities (biometric lock, background sync, push notifications for a
  daily check-in reminder), those would be added as Capacitor plugins on top of this
  same shell rather than requiring a rewrite.
- The Android project (`android/`) is committed to the repo, as is standard Capacitor
  practice — `android/app/src/main/assets/public` (the built web output) is
  gitignored and regenerated by `npm run android:sync`, so don't hand-edit it.
